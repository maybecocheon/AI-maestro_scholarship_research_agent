# 부산대 추진계획 HWPX 보고서

부산대학교 AX·정보화혁신본부가 쓰는 「추진계획」 서식(블루선 표지 + 네모 숫자 절 + 청회색 표)을
그대로 재현하는 한글 문서 생성기다.

## 서식을 지키는 방법: 자원 보존 + 본문만 재생성

이 서식의 시각 정체성(글꼴 8종, 테두리·채움 59종, 글자 스타일 86종, 문단 스타일 71종, 그리고
표지의 블루 그라데이션 막대와 대학 로고 이미지)은 전부 `header.xml`과 `BinData/`에 들어 있다.
이것들을 처음부터 다시 만들면 깨지기 쉽다.

그래서 **원본 패키지(`assets/template/`)를 통째로 보존**하고, 본문인 `Contents/section0.xml`만
다시 쓴다. 모든 요소는 원본 저자가 고른 **스타일 ID를 그대로 참조**하므로, 내용을 바꿔도 서식은
1도 흔들리지 않는다. 이것이 "더미 내용을 바꿔 실행해도 서식이 유지"되는 이유다.

## 사용법

내용을 파이썬 dict(또는 JSON) 하나로 기술하고 빌더를 돌린다.

```bash
cd scripts
# 1) 데모(모든 요소 시연) 그대로 생성
python build_report.py out.hwpx
# 2) 직접 만든 스펙(JSON)으로 생성
python build_report.py --spec my_spec.json out.hwpx
```

JSON 대신 파이썬에서 `build_report.build(spec, "out.hwpx")`를 직접 불러도 된다.
새 주제로 채울 때는 `scripts/demo_spec.py`를 복사해 값만 바꾸는 것이 가장 빠르다.

## 콘텐츠 스펙 구조

```python
{
  "title_top":  "2026년 제1회",              # 표지 윗줄(작은 글씨)
  "title_main": "샘플 업무 추진계획 보고서",   # 표지 큰 제목
  "date":       "2026.  7. ",                # 표지 가운데 날짜
  "dept":       ["○○혁신본부", "○○기획과"],  # 로고 오른쪽 부서(1~여러 줄)
  "sections": [
    { "number": 1, "title": "추진 개요",
      "items": [ ...아래 항목 타입... ] },
    ...
  ],
  "annexes": [ ...항목 타입, 보통 annex + 본문... ]
}
```

표지는 항상 1페이지 단독으로 놓이고, **첫 번째 번호 절이 2페이지에서 시작**한다(원본과 동일).
절에 `"page_break": 1`을 주면 그 절을 새 페이지에서 시작시킬 수 있다.

## 항목(item) 타입

`sections[].items` 와 `annexes` 에 넣는 블록들. `type` 으로 구분한다.

| type | 필드 | 렌더링 |
|------|------|--------|
| `bullet` | `text`, `label`(선택) | `◦ (label) text` — label은 굵게. 절의 기본 글머리. |
| `subbullet` | `text` | `- text` — ◦ 아래 하위 항목. |
| `note` | `text` | `※ text` — 표 밑 단서/각주. |
| `plain` | `text` | 마커 없는 일반 문단. |
| `table` | `headers`, `rows`, `total`(선택), `widths`(선택) | 청회색 머리행 그리드 표. `total`을 주면 옅은 노랑 **계** 행 추가. `widths`는 열 비율(예: `[2,6,2]`). 셀 값에 리스트를 주면 여러 줄. |
| `table_boxed` | `pairs`, `header`(선택) | 박스형 2열 표(왼쪽 라벨 + 왼쪽정렬 설명). `pairs=[[label, content], ...]`, content는 문자열 또는 줄 리스트. 긴 설명·다단 내용에 적합. |
| `annex` | `label`, `title`, `page_break`(기본 1) | 붙임 표제(cyan 번호 박스 + 제목). 기본으로 새 페이지 시작. |

예시는 `scripts/demo_spec.py` 참고 — 모든 타입을 한 번씩 쓴다.

## 서식 세부 규칙(요약)

- **용지·여백**: A4, 좌우 여백 7088, 상하 4536 (원본 secPr 그대로 보존).
- **글꼴**: 본문 굴림체, 큰 제목 HY헤드라인M — header.xml에 정의된 것을 그대로 사용.
- **표지 표**: 상·하단 블루 그라데이션 막대(#42C7F1→#3B4C97) + 회색(#F1F1F1) 제목 셀 + 로고.
- **절 표제**: navy(#3E57A5) 숫자 박스 + 아래 밑줄 제목.
- **표 머리행**: 청회색(#DFE6F7), **계** 행은 옅은 노랑(#FFF7CC).
- **붙임**: cyan(#079FCE) 번호 박스.

레이아웃 좌표(줄 높이 등)는 첫 렌더링 힌트일 뿐이라 한글이 열 때 다시 계산한다 — 정확할 필요 없다.

스타일 ID ↔ 서식 대응표 등 더 깊은 내부 규칙은 `references/format_spec.md` 참고.

## 검증(선택)

한컴오피스 한글이 설치돼 있으면 COM 자동화로 실제 렌더링을 확인할 수 있다.
`references/format_spec.md` 의 "한글로 열어 확인" 절에 PDF 내보내기 스니펫이 있다.
설치돼 있지 않아도 생성된 `.hwpx`는 그대로 한글에서 열린다.
