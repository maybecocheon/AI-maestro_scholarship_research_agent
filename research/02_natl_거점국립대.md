# 타대학 장학 제도 리서치 — 주요 거점국립대학교

- **조사원**: 타대학 조사원 — 주요 거점국립대학교 담당 (researcher-natl-univ)
- **주제**: 거점국립대의 교내(자체) 장학 제도·장학 공지
- **수집일시**: 2026-07-24
- **수집 대학**: 서울대학교, 부산대학교, 경북대학교, 전남대학교, 충남대학교 (5개교)
- **수집 방법**: 각 대학 공식 장학 페이지 직접 접속(agent-browser) + WebFetch/WebSearch 폴백

---

## 핵심 요약 (거점국립대 장학의 공통 패턴)

1. **성적우수형 / 소득연계(가계곤란)형 / 근로형** 3축이 공통 골격. 국립대는 등록금 자체가 사립 대비 낮아, 교내 장학은 "등록금 전액·일부 감면" + "생활비·학업장려금" 형태로 이원화된다.
2. **등록금 장학금은 이중수혜 불가·등록금 한도 내 지급**, 생활비/근로/장려금 등 '기타 장학금'은 이중수혜가 가능한 구조가 일반적이다(부산대 규정에 명문화).
3. **성적우수 장학생 선발은 학과·단과대 자율 기준**(성적+어학+인성+가계곤란 등 반영)으로 위임하는 경우가 많다(부산대·전남대·충남대 공통).
4. **신입생 유치용 수능성적 우수 장학**이 거점국립대의 특징적 제도로 강화됨(충남대 CNU Honor/Community/글로벌엘리트, 전남대 수능성적우수장학, 서울대 신입생 성적우수).
5. **국가장학금(Ⅰ·Ⅱ·다자녀·지역인재)이 소득연계 장학의 핵심 재원**이며, 교내 자체 재원(교비·발전기금·기부·동문)은 성적/특별/생활지원 장학에 집중된다.
6. 최근 공지 게시판은 **외부 재단(포스코청암, 지자체 인재육성재단 등) 장학 안내가 다수**를 차지 — 교내 자체 장학은 학기초 일괄 선발·신청 방식이라 상시 공지가 적다.
7. 장학 대상은 **학부 / 대학원 / 외국인 유학생**으로 구분 운영되며, 대학원은 조교(TA/RA)장학이 핵심(서울대·부산대·전남대 공통).

## 대학별 정리

### 1. 서울대학교

교내장학금은 크게 **등록금 면제형 / 생활비·학업장려형 / 근로형**으로 구분.

- **등록금 면제형**
  - 신입생 성적우수 장학: 단과대별 상위 2명 등록금 전액 면제(공대 제외).
  - 맞춤형 장학: GPA 학부 2.4↑·대학원 3.3↑, 소득 고려하여 등록금 일부·전액 면제.
  - 저소득 외국인 유학생 장학(지원구간 5구간 이하, GPA 2.4↑, 전액), 법정장학(국가·독립유공자, 북한이탈주민 전액), 동행장학(중증장애 학생 전액, 성적요건 없음).
- **생활비·학업장려형**
  - **선한인재장학금(월정)**: 지원구간 1~3구간, 월 40만~100만원.
  - 해외수학장학(교환학생, 8구간 이하, 연 최대 1,500만원), 긴급구호장학(긴급 위기 학생 등록금+생활비).
- **근로형**: 국가근로 등 근로장학(주 10~20시간, 3~8월/9~2월 6개월 단위), 대학원 TA(6개월 40만원).
- **신청 시기**: 1학기분 전년 11월말~12월 둘째주, 2학기분 5월말~6월 둘째주(학생포털).
- 출처: https://student.snu.ac.kr/대학생활/장학/교내장학금/ (확인 2026-07-24)
- 출처: http://scholarship.snu.ac.kr/sub02/sub_0201.html (확인 2026-07-24, 접속 시 간헐 오류)

### 2. 부산대학교

교내장학은 **성격별(등록금 장학금 / 기타 장학금)** × **대상별(학부 / 대학원 / 외국인)**로 이원 분류. 규정: 부산대학교 장학금규정(2019.7.31).

- **성격별**: 등록금 장학금(이중수혜 불가, 등록금 한도 내) / 기타 장학금(장려금·생활비·기숙사비·근로대가, 이중수혜 가능).
- **학부 대상 유형**
  - 성적우수형: premier(등록금+기타), 생명자원과학대학특별, 성적우수, 대통령과학, 국가우수(이공계/인문100년/예술체육비전), 희망사다리 등.
  - 소득연계형: 학업지원(소득분위), 학업지원(장학사정관), 생활지원형학업장려금, 유니웰, 근로봉사, 국가근로, 국가장학금(Ⅰ·Ⅱ·다자녀·지역인재) 등.
  - 우선선발형: 국가보훈대상자, 북한이탈주민 및 자녀, 특수교육대상자, 국가고시합격자, 형제자매, 체육특기자, 학군사관후보생, 국가거점국립대학 학사교류 등.
- **대학원**: 우수졸업자 진학, 학·석·박통합연계, 학부연계 premier, 성적우수(전문/특수대학원) / 장학조교·연구조교·학업지원.
- **외국인 유학생**: 유학생(학부/대학원), 외국인TOPIK, 정부초청외국인, 특별, 캠퍼스아시아.
- **장학급수**: A급(수업료·입학금 전액) / B급(수업료 전액) / C1급(50%) / C2급(25%) / D급(입학금 포함 전액).
- **최근 공지 예시**: "[장학] 포스코청암재단 2026년 포스코비전장학생 선발 안내"(2026-07-15) — 외부 재단 장학.
- 출처: https://onestop.pusan.ac.kr/page?menuCD=000000000000070 (우리대학장학금개요, 확인 2026-07-24)
- 출처: https://onestop.pusan.ac.kr/page?menuCD=000000000000242 (장학 메뉴·공지, 확인 2026-07-24)

### 3. 경북대학교

장학·복지 전용 포털(장학복지제도)에서 학부/대학원/외국인 장학을 안내. **2024년 기준 장학금 지원 규모 약 906억원**.

- **메뉴 구성**: 장학제도 안내 / 장학금 관련 일정 / 장학금 종류(학부·대학원·외국인) / 학자금대출 / 학생의료공제회 / 공지사항·FAQ.
- **담당(재원별 분리 운영)**: 교내장학금(053-950-2103), 국가장학금Ⅰ·Ⅱ·학자금대출(2106), 외부·농어촌재단·발전기금 장학(2105), 국가우수·대학원생 조교(RA/TA) 장학(2104), 국가근로장학(2107), 글로컬대학사업·BK21 장학(2108) — **교내/국가/외부/발전기금/조교 장학을 별도 창구로 운영**.
- **최근 공지 예시**(대부분 외부·지자체 재단 장학):
  - 2026년 화성시인재육성재단 (주)코나아이 소상공인 장학생 선발(신청 2026.7.20~8.11)
  - 2026년 서구인재육성재단 장학생 선발(2026.7.20~9.4, 지역인재 육성)
  - 정읍시민장학재단 우수인재 장학금(접수 2026.7.13~7.27)
  - 포스코청암재단 2027년도 비전장학생 모집(2026.6.15~7.19)
- 출처: https://home.knu.ac.kr/HOME/knussw/index.htm (장학복지제도 포털, 확인 2026-07-24)
- 출처: http://ssw.knu.ac.kr/ (장학·학자금대출 홈, 확인 2026-07-24)

### 4. 전남대학교

교내 장학 약 10여종 + 교외 장학 300여종, 전체 재학생의 약 40%가 장학 혜택. 등록금(입학금·수업료·기성회비) 재원 감면장학 중심.

- **성적우수(우수 장학)**: **진리장학금** — 성적 우수·품행 단정자, 등록금 전액~수업료1 지급. 학부 기준 직전학기 평균평점 2.5(79.99점)↑·12학점↑, 대학원 3.0(84.99점)↑.
- **복지(가계곤란) 장학**: 창조장학금(저소득층), 자립준비청년 장학금, 신입생 기초생활수급자 장학(전액), 장애학생 장학금, 응원장학금(가계곤란).
- **생활지원형**: 열정장학금(기관 봉사), 도전장학금(공인외국어·자기계발), 수능성적 우수장학금(신입생), 취업더하기장학금(취업계획서 제출).
- **대학원**: 교육조교·연구조교 장학(월 24만~32만원).
- **선발 방식**: 성적우수 장학생은 단과대·학부(과)별 자체기준(성적, 학생활동기록부, 가계곤란, 어학성적, 인성 등 자율 반영)으로 선발.
- **담당(재원별 분리)**: 학생과 062-530-1104(교내), 1084(교외·열정·미래성장), 1083(등록금재원감면·수능성적우수·응원장학) 등.
- 출처: https://www.jnu.ac.kr/MainUniLife/UniInfor/Promotion/InternalScholarship (교내장학금, 확인 2026-07-24)
- 출처: https://www.jnu.ac.kr/MainUniLife/UniInfor/Promotion/Scholarship (장학 일반, 확인 2026-07-24)

### 5. 충남대학교

신입생 유치형 성적 장학이 강한 편. 학생과 장학·학자금 페이지에서 안내.

- **신입생 장학(수능 성적 기반)**: **CNU Honor Scholarship Ⅰ/Ⅱ**(수능 우수, 등록금 전액+학업장려금), **CNU Community Scholarship**(인문·예체능 신입생 우수), **글로벌엘리트 A/B/C**(계열별 수능 최우수, 해외프로그램·대학원 진학 지원), **MEGA CNU GLOBAL**(지역고 졸업자, 1학년 어학교육·해외파견).
- **재학생 장학**: 성적우수·학업증진·격려 등급 구분(직전학기 평균평점 기준). 선발 기준은 학교성적 55%(직전학기 평균/4.5) + 개인성적 45%(어학성적 등 포함), 15학점↑ 이수.
- **복지·특별 장학**: 백마, 영탑(장애인), 체육특기자, 보훈, 외국어 우수 등.
- **지급 규모**: 등록금 전액~일부, 학업장려금 학기당 약 100만~750만원.
- 출처: https://plus.cnu.ac.kr/html/hub/support/support_030302.html (교내장학금, 확인 2026-07-24)
- 출처: https://plus.cnu.ac.kr/html/hub/support/support_030301.html (장학제도 안내, 확인 2026-07-24)

## 한계·미확인

- **미수집 대학**: 강원대, 전북대, 충북대, 경상국립대 — 시간·분량 제한(약 15분, 8~12페이지)으로 이번 회차에서 확인하지 못함. 다음 회차 확인 필요.
- **부산대·경북대 상세 금액/기준**: 학생지원시스템 상당수 페이지가 로그인(재학생 인증) 필요라 세부 지급액·선발 인원은 공개 개요 수준까지만 확인. 정확한 급별 금액·소득분위 컷오프는 로그인 후 「종류별 장학 안내」에서 확인해야 함.
- **금액 수치**: 서울대 월정 40~100만원, 충남대 학업장려금 100~750만원 등은 공개 안내 기준이며 연도·구간별로 변동될 수 있음(2026년 최신 공고 재확인 권장).
- **공지 신선도**: 각 대학 공개 게시판의 장학 공지는 외부 재단 장학이 다수. 교내 자체 장학의 학기별 신청 공고는 로그인 게시판(부산대) 또는 학과별 안내로 분산되어 있어 전수 확인은 미완.
- **경북대 장학금 종류 세부**: 포털 메뉴 구조와 담당 창구는 확인했으나 개별 장학 명칭·금액은 로그인 필요로 미확인.
